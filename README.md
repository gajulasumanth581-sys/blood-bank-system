
# Blood Bank Donor & Blood Inventory System

## About the Project
This project is a simple Blood Bank Management System developed using HTML, CSS and JavaScript.

It helps manage blood donors, blood donations, blood stock and blood requests.

## Features
- Donor Registration
- Blood Group Management
- Donation History
- Blood Inventory Management
- Blood Expiry Status
- Blood Request Management
- Blood Availability Search

## Technologies Used
- HTML
- CSS
- JavaScript

## Objective
The main objective of this project is to make blood bank management easier and help users check blood availability quickly.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
